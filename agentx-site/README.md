# AgentX Trace Atlas

Visual companion to the reproducible analysis of the SemiAnalysis AgentX Claude
Code trace corpus. The site presents measured context-length, timing, theoretical
prefix-reuse, and subagent-concurrency characteristics.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
npm test
```

The source measurements are generated by `../analyze_agentx.py`. Static chart
images in `public/plots/` come from `../agentx_outputs/plots/`.
